## Тема 18 — Определение необходимой мощности блока питания для ПК

Веб-приложение для подбора компонентов ПК и расчёта минимальной требуемой мощности
блока питания с учётом пиковых нагрузок и КПД.

- **Услуга** — компонент (процессор, видеокарта и др. из каталога)
- **Заявка** — конфигурация: расчёт БП для выбранного набора компонентов

Расчёт результата конфигурации:

```
мощность БП = (Σ TDP компонентов × количество × коэффициент пиковой нагрузки) / КПД БП
```
